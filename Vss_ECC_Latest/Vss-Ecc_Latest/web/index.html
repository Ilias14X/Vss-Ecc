Partage de secret vérifiable sur P-256
Shamir + engagements de Feldman.

Paramètres Partage Vérification Reconstruction Point P-256 Tests

Paramètres (k, n)

k = seuil, n = nombre de participants. Règle : (n − 1) mod (k − 1) = 0. Tout autre couple est rejeté.

Partage du secret (dealer)

Le secret est optionnel (entier ou hexadécimal 0x…, inférieur à l'ordre q de P-256) ; vide = secret aléatoire.


Vérification par chaque participant (Feldman)

Test : si·G = Σ ij·Cj. Cochez « corrompre » pour modifier une part (+1) et voir la détection.

Reconstruction

Choisissez des parts (au moins k pour retrouver le secret). Avec k − 1 parts, le résultat n'a aucun rapport avec le secret.

Validation d'un point de courbe

P-256 a un cofacteur 1 : tout point valide autre que l'infini est d'ordre q. Un point hors courbe ou d'une autre courbe est refusé.

Vérifications automatiques

Rejoue les contrôles clés : contrainte (n−1) mod (k−1), cofacteur, points invalides, RUSTSEC-2024-0398, anti-rejeu, partage complet.
